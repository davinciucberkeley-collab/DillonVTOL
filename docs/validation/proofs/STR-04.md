## Calculation

1. Step

$$I = \frac{\pi}{64}(D^4 - d^4)$$

$$=  \frac{\pi}{64}(0.0254^4 - 0.02362^4) = 5.15\times 10^{-9}\ \text{m⁴}$$

2. boom mass

$$m_b = \rho_{Al}\frac{\pi}{4}(D^2 - d^2)L$$

$$=  2700\frac{\pi}{4}(0.0254^2 - 0.02362^2)\times 0.4883 = 0.09026\ \text{kg}$$

3. first bending mode, cantilever with tip mass (Rayleigh)

$$f_1 = \frac{1}{2\pi}\sqrt{\frac{3EI}{(m_{tip} + 0.24\,m_b)L^3}}$$

$$=  \frac{1}{2\pi}\sqrt{\frac{3EI}{(0.3255 + 0.24\,\times 0.09026)\times 0.4883^3}} = 25.84\ \text{Hz}$$
