# STR-04: Boom first bending mode 34.4 Hz FEA vs 32.3 Hz hand; test pass band 26-41 Hz.

**Status: Partially Verified.** FEA and hand agree to 0.8 % on the same geometry, but both use a 0.242 kg tip mass while the CAD lift unit is 0.331 kg (STR-05): with the CAD mass f1 = 27.9 Hz, still well below the EST hover 1P of 86 Hz (2P 171 Hz). Rigid root overstates f1.

**✓ re-runs to 32.29 Hz** against the claim's 34.38 Hz (difference -6.08 %).

## Calculation

1. Step

$$I = \frac{\pi}{64}(D^4 - d^4)$$

$$=  \frac{\pi}{64}(0.0254^4 - 0.02362^4) = 5.15\times 10^{-9}\ \text{m⁴}$$

2. boom mass

$$m_b = \rho_{Al}\frac{\pi}{4}(D^2 - d^2)L$$

$$=  2700\frac{\pi}{4}(0.0254^2 - 0.02362^2)\times 0.462 = 0.08539\ \text{kg}$$

3. first bending mode, cantilever with tip mass (Rayleigh)

$$f_1 = \frac{1}{2\pi}\sqrt{\frac{3EI}{(m_{tip} + 0.24\,m_b)L^3}}$$

$$=  \frac{1}{2\pi}\sqrt{\frac{3EI}{(0.242 + 0.24\,\times 0.08539)\times 0.462^3}} = 32.29\ \text{Hz}$$
