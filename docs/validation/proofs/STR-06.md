## Calculation

1. lift on one wing

$$L_{half} = \frac{m g\, n_{ult}}{2}$$

$$=  \frac{7.436 \times 9.807\, \times 4.5}{2} = 164.1\ \text{N}$$

2. root moment, AVL span loading

$$M_{root} = L_{half}\,\bar{y}$$

$$=  164.1\,\times 0.5458 = 89.54\ \text{N·m}$$
